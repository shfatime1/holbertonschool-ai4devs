
# User Stories: Carpool Connect

### User Story 1: Search for Available Rides

As a passenger, I want to search for available rides by entering my pickup location and destination so that I can find a convenient ride.

**Acceptance Criteria:**
- User can enter a pickup location and destination.
- System displays available rides matching the selected route.
- Search results include departure time, available seats, and estimated cost.

**Priority**: MVP

### User Story 2: Offer a Ride

As a driver, I want to publish my planned trip so that passengers traveling in the same direction can join me.

**Acceptance Criteria:**
- Driver can enter the starting point, destination, date, and departure time.
- Driver can specify the number of available seats.
- Published rides are visible to passengers searching for matching routes.

**Priority**: MVP

### User Story 3: Book a Seat

As a passenger, I want to reserve an available seat so that I can secure transportation for my journey.

**Acceptance Criteria:**
- Passenger can select an available ride.
- System confirms the booking and updates the number of available seats.
- Passenger receives a booking confirmation.

**Priority**: MVP

### User Story 4: Create a User Profile

As a user, I want to create a personal profile so that other drivers and passengers can learn basic information about me.

**Acceptance Criteria:**
- User can register with an email address and password.
- User can add a profile photo and basic personal information.
- User can view and edit their profile.

**Priority**: MVP

### User Story 5: Communicate with Other Users

As a passenger, I want to message a driver so that I can clarify pickup details before the trip.

**Acceptance Criteria:**
- Passenger can send messages to a driver after selecting a ride.
- Driver can receive and reply to messages.
- Users can view their conversation history.

**Priority**: High

### User Story 6: Schedule Recurring Rides

As a driver, I want to schedule recurring trips so that I do not need to publish the same journey every day.

**Acceptance Criteria:**
- Driver can select specific days of the week.
- System automatically displays recurring rides on the selected days.
- Driver can edit or cancel a recurring schedule.

**Priority**: Medium

### User Story 7: Share Travel Costs

As a driver, I want to set an estimated cost per passenger so that I can share fuel and travel expenses fairly.

**Acceptance Criteria:**
- Driver can enter the estimated total trip cost.
- System calculates an estimated contribution per passenger.
- Passengers can see the estimated cost before booking.

**Priority**: MVP

### User Story 8: Rate and Review Users

As a passenger, I want to rate a driver after completing a trip so that other users can make informed decisions.

**Acceptance Criteria:**
- Users can submit a rating after a completed trip.
- Users can leave a written review.
- Ratings and reviews are displayed on user profiles.

**Priority**: High

### User Story 9: Receive Notifications

As a user, I want to receive notifications about my rides so that I stay informed about booking updates and schedule changes.

**Acceptance Criteria:**
- User receives a notification when a booking is confirmed.
- User is notified when a ride is cancelled or changed.
- Notifications display relevant ride information.

**Priority**: High

### User Story 10: Report Safety Concerns

As a user, I want to report inappropriate behavior or safety concerns so that the platform remains safe and trustworthy.

**Acceptance Criteria:**
- User can submit a report about another user or a specific ride.
- User can provide a description of the issue.
- Reports are available for administrator review.

**Priority**: Medium
