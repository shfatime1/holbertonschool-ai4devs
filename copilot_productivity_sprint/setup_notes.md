
# IDE and AI Assistant Setup Notes

## 1. IDE

- **IDE:** Visual Studio Code (VS Code)
- **Purpose:** Writing, editing, and testing code.
- **Operating System:** Linux (Ubuntu)

## 2. AI Coding Assistant

- **Assistant:** GitHub Copilot
- **Copilot Chat:** Used to ask coding questions, explain code, and generate code suggestions.

## 3. Installation Steps

1. Download and install Visual Studio Code from https://code.visualstudio.com/.
2. Open VS Code.
3. Go to the Extensions marketplace.
4. Search for GitHub Copilot.
5. Install the GitHub Copilot extension.
6. Install GitHub Copilot Chat if it is not installed automatically.
7. Sign in using a GitHub account.
8. Complete the authentication process.
9. Open Copilot Chat and test it with a simple coding question.

## 4. Installed Extensions

| Extension | Purpose |
|---|---|
| GitHub Copilot | Provides AI code suggestions |
| GitHub Copilot Chat | Allows interaction with an AI coding assistant |

## 5. Tool Versions

| Tool | Version |
|---|---|
| Visual Studio Code | Latest stable version |
| GitHub Copilot | Latest available version |
| GitHub Copilot Chat | Latest available version |
| Git | Latest installed version |

*Note: Exact version numbers can be checked in VS Code and the terminal.*

## 6. Testing

After installation, I tested GitHub Copilot by:

- Asking Copilot to explain a code snippet.
- Requesting a simple code suggestion.
- Using Copilot Chat to understand programming concepts.

The assistant provided useful suggestions and explanations that can help improve coding productivity.

## 7. Conclusion

Visual Studio Code and GitHub Copilot provide a useful development environment. Copilot helps write code faster, understand errors, and improve programming efficiency.
